# Constelación · un juego de COCO Health

El juego para amigos que creen que ya se conocen. Cinco actos (Chispa, Raíces, Asombro, Lo profundo y Cariño), de 3 a 8 personas, un solo celular.

**Jugar:** https://lauzulu.github.io/constelacion/

- Funciona en cualquier celular, tablet o computador. Se puede *agregar a la pantalla de inicio* como app y funciona sin internet después de la primera visita.
- Las respuestas nunca se guardan ni se envían a ningún lado: el juego es oral y el celular solo muestra las cartas.
- Es un juego para conectar y no reemplaza la atención profesional. En Colombia: Línea 106 (Bogotá), Línea 192 opción 4, Línea 123.

Hecho por [COCO Health](https://cocohealth.app).
